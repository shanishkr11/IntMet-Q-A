Q1

What is an array and why is it used?

Improved Explanation

An array is a fixed-size collection used to store multiple values of the same data type in

continuous memory.

Think of it like keeping items in labeled lockers placed side-by-side — every locker has equal size and fixed count.

Why Arrays Are Useful

When you already know how many items you want to store

When you want fast and direct access using index

When memory efficiency matters

Real-Time Industry Example

Suppose a finance team tracks monthly revenue data. We know months = 12 (fixed). So the array is perfect.

int[] monthlySales = { 12000, 15000, 18000, 20000 }; Console.WriteLine(monthlySales[2]); // Output: 18000

Common Interview Mistakes

❌ Saying “arrays are dynamic”

❌ Saying “array grows automatically”

Why is array index access O?

Improved Explanation

Array elements are stored continuously in memory.

So to access an element, computer directly calculates its location using formula:

Address = BaseAddress + (Index × SizeOfEachElement)

No loop, no searching, no scanning → Direct jump, so it's constant time O(1)

Real-Time Example

Fetching employee salary by index

int[] salaries = { 30000, 40000, 50000 }; int empSalary = salaries[1];

Interview Winning Line

“It is O(1) because arrays support direct memory indexing due to contiguous allocation.”

How do you find the second largest element in an array? Why interviewer asks

To see whether you can solve logically without shortcuts like sorting.

Explanation

We scan array only once and maintain:

first → largest number

second → second largest

Whenever we find a bigger value than first, we shift first → second.

Real-time C# Example

int[] scores = { 65, 85, 90, 70 };

int first = int.MinValue, second = int.MinValue;

foreach(int s in scores)

{

if(s > first)

{

second = first; first = s;

}

else if(s > second && s != first)

{

second = s;

}

}

Edge Cases

All values same → second largest doesn’t exist

Array length < 2 → invalid

Real Project Usage

Finding:

2nd highest revenue month

Runner-up performance score

What is Bubble Sort?

Explanation

Bubble Sort is a simple comparison-based sorting technique.

It repeatedly compares adjacent elements and swaps them when they are in the wrong order.

After each iteration, the largest element “bubbles up” to its correct position.

Real-time C#

int[] arr = { 5, 3, 2, 4 };

for (int i = 0; i < arr.Length; i++)

{

for (int j = 0; j < arr.Length - i - 1; j++)

{

if (arr[j] > arr[j + 1])

{

int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp;

}

}

}

Interview Note

Used mainly for learning purposes, not real production.

Q49
AccentureDeveloper Round

What is Selection Sort?

Explanation

Selection Sort finds the smallest element in the unsorted part and places it at the correct position.

Fewer swaps but still O(n²).

Real-time C#

for (int i = 0; i < arr.Length; i++)

{

int min = i;

for (int j = i + 1; j < arr.Length; j++) if (arr[j] < arr[min])

min = j;

int temp = arr[i]; arr[i] = arr[min]; arr[min] = temp;

}

Q51

What is Insertion Sort?

Explanation

Insertion Sort builds the final sorted array one element at a time.

It shifts elements and inserts the new element in its correct position.

Real-time C#

for (int i = 1; i < arr.Length; i++)

{

int key = arr[i]; int j = i - 1;

while (j >= 0 && arr[j] > key)

{

arr[j + 1] = arr[j]; j--;

}

arr[j + 1] = key;

}

Real Usage

Very efficient when data is:

Small in size

Already almost sorted (like logs, small UI lists)
